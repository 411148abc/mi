## 为什么 `测试/` 也能砍掉

实测过：**exe 是自包含的**，用例已经打进二进制，不需要外部数据。

| 场景 | 去掉 `测试/` 后 |
|---|---|
| `mi-browser.exe --selftest` | **63/63 passed** |
| `mi.exe run f.mi` | 正常 |
| `mi-c.exe run f.mi` | 正常 |
| `python -m 米 browser --selftest`（从源码跑） | `no conformance cases found` |

只有「克隆源码后用 Python 跑自测」这一条路径会失效，正常执行程序不受影响。
用例本身仍留在 `网页浏览器/js/conformance.js`（22.7 KB，编译进网页版），
以及三个 exe 内部。

## 保留项及理由

1. **`第三方许可证/`（4 文件）**
   `mi.exe` / `mi-browser.exe` 内含 Python、Tcl/Tk、Pillow、PyInstaller bootloader。
   **分发 exe 必须附许可证全文**，法律要求。只搬了许可证，PyInstaller 配置已删。
2. **`c/tables.h`（随源码）**
   `规格/glyphs.json` 的生成物，但 C 版编译需要它。`工具/` 已砍，所以 README 里
   给了一条 `zig cc` 直接编译的命令。
3. **`hello.mi`（根目录）**
   保证 README 里 `mi.exe run hello.mi` 这条命令能直接跑。
