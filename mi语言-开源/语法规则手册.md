## 1. 一句话理解 MI

> **信号，而非语句。** 程序不是"一条条命令"，而是一块电路。

| 别的语言 | MI 的写法 |
|---|---|
| `x = 1`（赋值） | `emit x: 1`（把值注入线） |
| `if cond { }` | `when cond { }`（门） |
| `for` / `while` | `cycle`（循环：计数 / while / until / over） |
| `def f()` + `return` | `station f() { out value: … }`（站点 + 具名端口） |
| 对象 / struct | `assembly{ … }`（装配体，不可变） |
| 变量可随意改 | 只有 `wire` 可变，其余值永不可变 |

**五条法则**（详细解释见 [`SPEC.md` §1](SPEC.md)）：

1. 没有赋值 —— 状态只存在于 `wire` 里，`emit` 注入、`draw` 读取。
2. 没有 `if` / `for` —— 条件用 `when`，重复用 `cycle`。
3. 值永不改变 —— `push`、`place`、`sort` 都返回新值。
4. 站点有具名端口 —— 参数是输入端口，`out` 是输出端口。
5. **拼写也是契约** —— 每个关键字/运算符/内置函数都有多种等价写法。

## 2. 程序的基本形状

一个 MI 程序由**条目**（item）组成，条目分四类：

```
use "模块.mi" as 别名        -- 导入
~计数: 0                     -- 声明 wire
station 平方(n) { … }        -- 声明站点
show("hello")                -- 普通流程（表达式）
```

**block（块）** 里放**流程**（flow），流程共 8 种：

| 流程 | 写法 | 作用 |
|---|---|---|
| 表达式 | `show(1)` | 求值并丢弃结果（副作用在里面） |
| 注入 | `emit 计数: 计数 + 1` | 往 wire 里写值 |
| 门 | `when c { … } otherwise { … }` | 条件分支 |
| 循环 | `cycle 3 as i { … }` | 重复 |
| 输出端口 | `out value: 42` | 往站点的输出端口写值 |
| 返回 | `return 值` | 立刻离开站点 |
| 中止 | `halt` | 离开最近的循环 / 站点 |
| 跳过 | `skip` | 进入最近的循环的下一轮 |

**最小可运行程序：**

```mi
show("hello, mi")
```

**带状态的程序：**

```mi
~计数: 0
cycle 3 {
    emit 计数: 计数 + 1
}
show(计数)          -- 3
```

**带站点的程序：**

```mi
station 平方(n) {
    out value: n * n
}
show(平方(5))       -- 25
```

## 3. 词法规则

### 3.1 源文件

- **编码**：UTF-8，扩展名 `.mi`。
- **BOM**：带 BOM 的文件会被**拒绝**（`E0001`），不是被剥离。请保存为无 BOM 的 UTF-8。
- **行列号**：从 1 开始计。
- **分隔**：条目与流程之间用**换行**或**单个分号** `;` 分隔。连续分隔符合并成一个，所以空行随意。
- **闭合前的分隔符可省**：`}` 或 `end` 之前的分隔符可写可不写；文件末尾也可以没有分隔符。

### 3.2 注释

| 写法 | 到哪结束 | 说明 |
|---|---|---|
| `# …` | 行尾 | |
| `-- …` | 行尾 | **优先级最高**，紧跟在表达式后面也是注释 |
| `;; …` | 行尾 | 一个 `;` 是分隔符，**两个**才是注释 |
| `/* … */` | 闭合符 | **不嵌套** |
| `(* … *)` | 闭合符 | **不嵌套** |

```mi
show(1) -- 这是注释
show(2);; 整行剩余部分被吞掉，所以下面这行不会执行
-- show(3)
```

⚠️ `//` **不是**注释，它是**整除**运算符。

⚠️ 因为 `--` 是注释，想表达"减去一个负数"必须加空格：

```mi
show(5 - -2)        -- 7        ✅
show(5--2)          -- ❌ 解析错误，被当成注释
```

⚠️ `show(1);; show(2)` 只执行 `show(1)` —— `;;` 把该行剩余部分全变成注释。

### 3.3 字符串

三种写法，等价的文本：

| 开 | 闭 | 例 |
|---|---|---|
| `"` | `"` | `"文本"` |
| `'` | `'` | `'文本'` |
| `«` | `»` | `«文本»` |

**全部转义序列：**

| 转义 | 含义 |
|---|---|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\r` | 回车 |
| `\0` | NUL |
| `\\` | 反斜杠 |
| `\"` | 双引号 |
| `\'` | 单引号 |
| `\«` `\»` | 书名号本身 |
| `\u{H…}` | 码点，**必须带花括号**，1–6 位十六进制 |

```mi
show("第一行\n第二行")
show("\u{41}")          -- A
show("\u{1F600}")       -- 😀
show(len("a\0b"))       -- 3
```

❌ **不存在** `\b`、`\f`。
❌ `"\u0041"`（无花括号）是错误 `E0003`。
❌ 其他未知转义都是 `E0003`。

**续行**：反斜杠紧跟换行时，换行被丢弃，字符串继续：

```mi
show(len("a\
b"))        -- 2
```

**不插值**：字符串里不能嵌变量，用 `join` 拼接。

### 3.4 数字

| 写法 | 值 |
|---|---|
| `123` | 整数 |
| `1_000` | 整数（下划线可读性分隔） |
| `0x1F` | 十六进制，31 |
| `0b1010` | 二进制，10 |
| `1.5` | 实数 |
| `.5` | 实数，0.5 |
| `1e3` | 实数，1000 |
| `1.5e-3` | 实数，0.0015 |

⚠️ **数字字面量不自带符号**。`-2` 是"一元负号作用于 2"。
这直接导致 `-2 ** 2` 等于 **4**（不是 −4），见 [§5 优先级](#5-运算符与优先级)。

### 3.5 标识符

- 首字符：字母（**任意 Unicode 字母**，所以 `名字` 合法）或 `_`。
- 后续：字母、数字、`_`。
- **大小写敏感**：`Count` 与 `count` 是两个名字。

⚠️ 单独的 `_` 是 nothing 字面量，**不能当标识符**：

```mi
~_: 1           -- ❌ E0100
~_x: 1          -- ✅
```

### 3.6 关键字的大小写与边界

- 关键字、运算符、字面量词 **大小写不敏感**：`SHOW`、`When`、`ON`、`AND` 都能用。
- 但**单词拼写必须落在词边界上**：
  - `wiredup`、`whenx` 是**普通标识符**，不是 `wire`/`when` 加后缀。
  - 符号拼写是**精确匹配**，不需要分隔：`~x:1`、`x<-1` 都合法。
- 内置函数的**单词别名**是普通标识符，可以被 wire 遮蔽（编译器给 `W0102` 警告）。

## 4. 完整文法（EBNF）

```
program      ::= item*
item         ::= use | wire | station | flow

use          ::= "use" TEXT ("as" IDENT)?
wire         ::= "wire" IDENT ((":" | "=") expr)?

station      ::= "station" IDENT "(" params? ")" block
params       ::= param ("," param)*            (* 逗号必需，不允许尾逗号 *)
param        ::= IDENT ((":" | "=") expr)?

block        ::= "{" flow* "}" | ("do" | "begin") flow* "end"

flow         ::= emit | when | cycle | for | out | return | halt | skip | expr
emit         ::= "emit" IDENT (":" | "=" | "<-" | "<<" | "⇒") expr
               | IDENT ("<-" | "<<" | "⇒") expr
when         ::= "when" expr ("then")? block
                 ("otherwise" (when | block))?
cycle        ::= "cycle" (expr | "while" expr | "until" expr | "over" expr)
                 ("as" IDENT)? block
for          ::= "for" IDENT "in" expr block
out          ::= "out" IDENT (":" | "=") expr   (* 值必需 *)
return       ::= "return" (expr | 块末)
halt         ::= "halt"
skip         ::= "skip"

expr         ::= unary (infix-op expr)*         (* 优先级爬升 *)
unary        ::= (not-op | "-") unary | postfix
postfix      ::= primary ( "." IDENT
                        | "(" args? ")"
                        | implicit-args )*
implicit-args::= arg ("," arg)*
args         ::= arg (( "," )? arg)* ","?       (* 逗号可省，尾逗号允许 *)

arg          ::= (IDENT (":" | "="))? expr

primary      ::= NUMBER | TEXT | FLAG | NIL | IDENT
               | "[" (expr (( "," )? expr)*)? ","? "]"
               | "⟨" (expr (( "," )? expr)*)? ","? "⟩"
               | "assembly" "{" (field (( "," )? field)*)? ","? "}"
               | "draw" IDENT
               | "(" expr ")"
field        ::= key (":" | "=") expr
                 (* key 可以是标识符，也可以是任意单词记号，如 kind / text / none *)
```

### 4.1 标点：哪里可以省，哪里必须写

| 位置 | 逗号 | 尾逗号 |
|---|---|---|
| 函数调用 `f(…)` | **可省**：`show(1 2)` | **允许**：`show(1, 2,)` |
| 列表 `[…]` `⟨…⟩` | **可省**：`[1 2]` | **允许**：`[1, 2,]` |
| 装配体 `assembly{…}` | **可省**：`assembly{a: 1 b: 2}` | **允许**：`assembly{a: 1,}` |
| **站点参数表 `station f(…)`** | **必须写**：`station f(a, b)` | **不允许**：`station f(a,)` ❌ |

**`:` 与 `=` 完全等价**，6 个位置都能互换：

```mi
~x = 1                  等价于  ~x: 1
emit x = 1              等价于  emit x: 1
out value = 1           等价于  out value: 1
station f(a = 1)        等价于  station f(a: 1)
f(items = [1])          等价于  f(items: [1])
assembly{a = 1}         等价于  assembly{a: 1}
```

### 4.2 调用：括号可省

```mi
show 1                  -- 隐式调用，一个参数
show 1, 2               -- 隐式调用，两个参数
show value: 1           -- 带标签
show(value: 1)          -- 括号 + 标签
show len("ab")          -- 嵌套隐式调用
```

隐式调用中，第一个参数**尽可能长地延伸**，后续参数用逗号分开。

### 4.3 两种块写法

```mi
when on { show(1) }                     -- 花括号
when on do show(1) end                  -- do … end
when on begin show(1) end               -- begin … end
when on do when on do show(1) end end   -- 可嵌套
```

`otherwise` 也接受两种块：

```mi
when off { show(1) } otherwise { show(2) }
when off { show(1) } otherwise do show(2) end
```

⚠️ `otherwise` **后面必须有块**，不能直接跟裸表达式：

```mi
when off { show(1) } otherwise show(2)   -- ❌ E0102
```

### 4.4 门链（替代 elif）

```mi
when n is 0 {
    show("零")
} otherwise when n below 0 {
    show("负")
} otherwise {
    show("正")
}
```

### 4.5 四种循环

```mi
cycle 5 as i { show(i) }                      -- 计数：i = 0..4
cycle while n below 10 { emit n: n + 1 }      -- 先测条件
cycle until n atleast 10 { emit n: n + 1 }    -- 条件成立就停
cycle over [1, 2, 3] as x { show(x) }         -- 遍历列表
for x in [1, 2, 3] { show(x) }                -- 遍历的另一种写法
```

计数运行时要求：**非负数字**（否则 `E0300`）。
`over` / `for` 运行时要求：**列表**（否则 `E0300`，不是崩溃）。

### 4.6 站点与端口

```mi
station 拆分(n) {
    out whole: n // 2
    out rest: n % 2
}

station 双倍(n) { out value: n * 2 }

show(双倍(4))        -- 8      1 个端口 ⇒ 直接是值
~s: 拆分(7)
show(s.whole, s.rest) -- 3 1   2 个端口 ⇒ 装配体
```

**端口收敛规则：**

| 端口数 | 结果 |
|---|---|
| 0 个 | `nothing` |
| 1 个 | 该值本身 |
| ≥2 个 | 字段名为端口名的装配体 |

**其它规则：**

- 站点**只能在顶层声明**，不能嵌套（`E0206`）。
- 站点**没有闭包**：函数体看不到顶层 wire，数据只能走端口。
  ```mi
  ~全局: 9
  station f() { out value: 全局 }   -- ❌ E0203 unknown name `全局`
  ```
- 参数是**只读端口**，不能 `emit`（`E0202`）。
- `return 值` 等价于 `out value: 值` 然后立刻离开。
- `return` 不带值 = 不带额外端口地离开。
- 递归允许，但受深度限制（`E0306`，默认 400 帧）。
- 站点体内**可以**声明局部 wire，每次调用都是全新的：
  ```mi
  station f() { ~临时: 1 out value: 临时 }
  ```

### 4.7 模块

```mi
use "库/数学.mi"              -- 平铺导入：数学.mi 的站点可直接用
use "库/数学.mi" as 数         -- 别名导入：数.双倍(…)
```

- 路径**相对发起 `use` 的那个文件**解析（不是进程 cwd，不是仓库根）。
- `.mi` 后缀可省。
- 模块只加载一次；循环引用是错误（`E0307`）。
- 导入**不执行**被导入文件的顶层流程，只登记它的站点。
- 找不到文件 → `E0307`。

## 5. 运算符与优先级

### 5.1 优先级表（越靠上越紧）

| # | 层级 | 结合性 | 见证表达式 → 结果 |
|---|---|---|---|
| 1 | `.` 取成员、`(…)` 调用、隐式调用 | 左 | `show len("ab")` → `2` |
| 2 | 前缀 `not` `!` `¬`、一元 `-` `minus` | 右（可嵌套） | `-2 ** 2` → `4` |
| 3 | `**` `power` `^` | **右** | `2 ** 3 ** 2` → `512` |
| 4 | `*` `times` `×`、`/` `div` `÷`、`//` `intdiv`、`%` `mod` `rem` | 左 | `100 / 10 / 2` → `5` |
| 5 | `+` `plus`、`-` `minus` | 左 | `10 - 3 - 2` → `5` |
| 6 | 比较：`==` `is`、`!=` `isnot`、`<` `below`、`<=` `atmost`、`>` `above`、`>=` `atleast` | 左（见下） | |
| 7 | `and` `&&` `∧` | 左 | `on or off and off` → `on` |
| 8 | `or` `\|\|` `∨` | 左 | |

### 5.2 两条反直觉的规则

**① 前缀运算符比所有中缀都紧，包括 `**`**

```mi
show(-2 ** 2)        -- 4    = (-2) ** 2
show(-(2 ** 2))      -- -4
show(not 1 is 1)     -- off  = (not 1) is 1
show(not 1 below 2)  -- ❌ 运行时 E0300（在比较 flag 与 number）
```

**② 比较运算符可以链写**

`规格/glyphs.json` 把六个比较运算符标为 `assoc: "none"`，但**解析器没有强制非结合**：

```mi
show(1 < 2 < 3)      -- 解析成 (1 < 2) < 3
                     -- 通过静态检查，**运行时报 E0300**
show(1 is 1 is on)   -- 解析成 (1 is 1) is on → on（合法但难懂）
```

👉 想表达"1 < 2 且 2 < 3"，写 `1 < 2 and 2 < 3`。

### 5.3 运算符重载

| 运算符 | 数字 | 文本 | 列表 | 装配体 |
|---|---|---|---|---|
| `+` | 相加 | 拼接 | 连接 | **合并**（右边覆盖左边） |
| `*` | 相乘 | 重复 | 重复 | — |
| `-` `/` `//` `%` `**` | 算术 | — | — | — |
| `<` `<=` `>` `>=` | 比较 | 比较（字典序） | — | — |
| `==` `!=` | 结构相等（贯穿所有类型） | | | |

```mi
show("a" + "b")                       -- ab
show([1] + [2])                       -- [1, 2]
show(assembly{a: 1} + assembly{b: 2}) -- assembly{a: 1, b: 2}
show("ab" * 2)                        -- abab
show([1] * 3)                         -- [1, 1, 1]
```

### 5.4 短路

`and` / `or` **短路**，且返回**被选中的那个操作数**（不是强制转成 flag）：

```mi
show(off and (1 // 0))     -- off    右侧不执行
show(on or (1 // 0))       -- on     右侧不执行
show(nothing or "默认值")   -- 默认值
```

## 6. 关键字全表（23 组）

### 6.3 结构与块

## 10. 拼写规则速查

### 10.1 大小写

```
show(1)   SHOW(1)   Show(1)        -- 都行
when      WHEN      When           -- 都行
on        ON        On             -- 都行
```

### 10.2 单词 vs 符号

| | 单词拼写 | 符号拼写 |
|---|---|---|
| 大小写 | 不敏感 | 精确 |
| 词边界 | **必须** | 不需要 |
| 例 | `wire` `when` `station` | `~` `?` `§` |

### 10.3 常见等价对

```mi
~x: 0                    ≡  wire x: 0            ≡  channel x: 0
emit x: 1                ≡  x <- 1               ≡  x ⇒ 1
show(draw x)             ≡  show(x)              ≡  show(@x)
when c { } otherwise { } ≡  if c { } else { }    ≡  gate c { } ⁇ { }
station f() { }          ≡  def f() { }          ≡  fn f() { }  ≡  § f() { }
out value: 1             ≡  yield value: 1       ≡  ↑ value: 1
cycle 3 { }              ≡  loop 3 { }           ≡  ↻ 3 { }
return 1                 ≡  ret 1                ≡  ← 1
use "m.mi"               ≡  import "m.mi"        ≡  ⇐ "m.mi"
assembly{a: 1}           ≡  record{a: 1}         ≡  ¤{a: 1}
```

### 10.4 内置函数的符号别名

```mi
»(1)              ≡  show(1)
⌗("abc")          ≡  len("abc")
≡([1,2], f)       ≡  map([1,2], f)
⋔([1,2], f)       ≡  filter([1,2], f)
∑([1,2], 0, f)    ≡  fold([1,2], 0, f)
⟷(0, 3)           ≡  span(0, 3)
```

## 11. 错误码全表

**两个阶段**：检查期（词法/语法/静态，`E0xxx`/`E02xx`，退出码 1）与运行期（`E03xx`，退出码 2）。

### 11.1 词法 / 语法

| 码 | 含义 | 例 |
|---|---|---|
| `E0001` | 非法字符 / BOM | `$`、文件开头的 BOM |
| `E0002` | 未闭合的文本或注释 | `show("abc` |
| `E0003` | 非法转义 | `"\q"`、`"\u0041"` |
| `E0004` | 非法数字 | `0xZZ` |
| `E0100` | 意外的记号 | 语法结构不对 |
| `E0101` | 未知关键字 / 名字 | `wenn on { }` |
| `E0102` | 缺少块或终止符 | `otherwise show(2)`、`out done` |
| `E0103` | 参数列表错误 | `station f(a b)` |

### 11.2 静态检查

| 码 | 含义 | 例 |
|---|---|---|
| `E0200` | 读未声明的 wire | `show(draw 计数)` |
| `E0201` | 重复声明 | `~x: 1` 两次 |
| `E0202` | 参数是只读端口 | `station f(n) { emit n: 1 }` |
| `E0203` | 未知站点 / 内置 / 名字 | `show(nope(1))` |
| `E0204` | 未知或重复的实参标签 | `f(x: 1)` |
| `E0205` | 缺少必需实参 | `f()` 少参数 |
| `E0206` | 该语句不允许在此处 | 顶层 `out`、嵌套 `station` |

### 11.3 运行期

| 码 | 含义 | 例 |
|---|---|---|
| `E0300` | 类型不匹配 | `1 + "a"`、`cycle over 5` |
| `E0301` | 除以零 | `1 // 0` |
| `E0302` | 端口未产出 | 读多端口站点的缺失字段 |
| `E0303` | 不可调用 | `~x: 1` 然后 `x(2)` |
| `E0304` | 循环外 `skip` | 顶层 `skip` |
| `E0305` | 步数超预算 | 默认 5,000,000 步 |
| `E0306` | 递归超深 | 默认 400 帧 |
| `E0307` | 模块问题 | 找不到 `.mi`、循环引用 |
| `E0308` | 宿主不可用 | 浏览器里调 `fs.read` |
| `E0309` | 宿主 I/O 失败 | 文件/网络/存储错误 |

### 11.4 警告（不阻止执行）

| 码 | 含义 |
|---|---|
| `W0100` | wire 已声明但从未读取 |
| `W0101` | 循环没有出口（无 `halt`） |
| `W0102` | 名字遮蔽了同名内置函数 |
| `W0103` | 不可达的语句 |

```bash
python -m 米 check 程序.mi                    # 报错误 + 警告
python -m 米 check 程序.mi --runtime selfhost  # 只报错误（自举版不产生警告）
```

## 12. 常见坑（实测确认）

### 12.1 `--` 是注释，`a - -b` 要加空格

```mi
show(5 - -2)     -- 7     ✅
show(5--2)       -- ❌ 后面的 -2 被当注释
```

### 12.2 `;;` 会吞掉整行剩余部分

```mi
show(1);; show(2)    -- 只输出 1
```

### 12.3 `-2 ** 2` 是 4，不是 -4

前缀负号比 `**` 更紧。想得到 -4 写 `-(2 ** 2)`。

### 12.4 比较不能链写

```mi
show(1 < 2 < 3)          -- 运行时报 E0300
show(1 < 2 and 2 < 3)    -- ✅
```

### 12.5 站点参数表必须有逗号

```mi
station f(a, b) { … }    -- ✅
station f(a b) { … }     -- ❌ E0103
station f(a,) { … }      -- ❌ E0100
```

其它地方（调用/列表/装配体）逗号可省，就参数表不行。

### 12.6 站点看不到顶层 wire

```mi
~全局: 9
station f() { out value: 全局 }    -- ❌ E0203
```

数据必须通过端口传进去。

### 12.7 只有 `_x` 能当名字，`_` 不能

```mi
~_: 1        -- ❌ E0100（_ 是 nothing 字面量）
~_x: 1       -- ✅
```

### 12.8 `out` 的值是必需的

```mi
station f() { out done }        -- ❌ E0102
station f() { out done: 1 }     -- ✅
```

### 12.9 循环里改了条件必须用 `emit`

```mi
~i: 0
cycle while i below 3 {
    show(i)
    emit i: i + 1        -- 忘了这句就死循环（W0101 会提醒）
}
```

### 12.10 `for` / `cycle over` 不吃文本

```mi
cycle over "abc" { … }    -- ❌ 运行时 E0300
```

要遍历文本请用 `cycle while i below len(s) { at(s, i) }`。

### 12.11 装配体的键可以是关键字

```mi
show(assembly{ kind: 1, text: 2, none: 3 })    -- ✅
show(assembly{ "x": 1 })                       -- ❌ E0100，键必须是标识符/单词
```

### 12.12 桌面版和网页版的宿主能力不同

```mi
fs.read(path: "a.txt")    -- 桌面版 ✅ / 网页版 ❌ E0308
view.card(…)              -- 桌面版 ✅ / 网页版 ❌ E0308
ui.button(…)              -- 两个版本都 ✅
```
